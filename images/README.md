# Imagens do Portfólio

Esta pasta é destinada às imagens reais do portfólio da empresa.

## Como adicionar imagens

1. Coloque as fotos dos projetos realizados nesta pasta
2. Formatos recomendados: `.jpg`, `.webp` (melhor compressão)
3. Tamanho recomendado: largura de 800–1200px
4. Nomeie os arquivos de forma descritiva, ex: `bancada-cozinha-granito-01.jpg`

## Atualizando o portfólio no site

No arquivo `index.html`, na seção `#portfolio`, substitua as URLs do Unsplash pelas URLs locais das suas imagens:

```html
<img src="images/seu-arquivo.jpg" alt="Descrição do projeto" />
```
